# Квиз-подарок для Никиты — ТЗ для Claude Code

Мобильное веб-приложение — подарок на 23-летие другу Никите. Никита проходит квиз из 23 вопросов о себе и друзьях (по одному за каждый год), а в конце узнаёт главный подарок: **прыжок с парашютом**. Подарок до самого конца держится в секрете.

Приложение открывают по ссылке на телефоне Никиты, рядом сидят друзья — «жюри». Часть ответов Никита пишет, часть выбирает, часть говорит вслух.

---

## 1. Что в этой папке

| Путь | Что это |
|---|---|
| `HANDOFF.md` | Это ТЗ |
| `questions.json` | Все вопросы, типы, варианты, правильные ответы и синонимы |
| `design/*.html` | Макеты всех экранов (390×844). Открываются в браузере. Это **референс внешнего вида**, а не готовый код: перенеси стили и разметку в компоненты |
| `assets/` | Фото и видео к вопросам, фото Никиты (`nikita.jpg`), стикер для 10-го вопроса |

Порядок макетов: `00-welcome` → вопросы `q01…q17` → `90-answer-correct` → `91-before-gift` → `92-plane-shake` → `93-parachute-drop` → `94-ticket`. Файл `tpl-question-photo-choice.html` — базовый шаблон вопроса с выбором.

## 2. Технологии (рекомендация)

- Vite + React + TypeScript (или чистый HTML/CSS/JS — на твоё усмотрение, главное: просто и надёжно).
- Без бэкенда. Все данные в `questions.json`, медиа лежат в `public/assets/`.
- Прогресс сохраняется в `localStorage`: если Никита случайно закроет вкладку, он продолжит с того же вопроса.
- Деплой на Vercel или Netlify, чтобы получить одну ссылку. **Нужен HTTPS** — без него на iPhone не работает датчик тряски.
- Вёрстка только под телефон (390–430 px по ширине). На компьютере показывать экран телефона по центру на розовом фоне.

## 3. Дизайн-система

Стиль: «пропуск за кулисы» — розовая сцена, софиты сверху, бейджи на шнурке, тексты голосом лучшей подружки.

**Цвета**
- Фон: `#FFD6EA` (нежно-розовый)
- Основной текст и тёмные кнопки: `#1A1020`
- Акцент: `#E0167A` (ярко-розовый)
- Вторичный текст: `#5C3A4E`
- Голубой акцент (лучи, детали): `#7FC8F8`
- Светло-розовые подложки: `#FFE9F3`, рамки `#F3BCD6`
- Карточки: `#FFFFFF`
- Верный ответ (подсветка поля): рамка `#1F9D55`, фон `#E8F7EE`

**Шрифты (Google Fonts)**
- Заголовки: **Playfair Display**, italic, 900
- Всё остальное: **Montserrat**, 500–900
- Моноширинный (только для декора, если понадобится): JetBrains Mono

**Общие элементы**
- **Софиты**: 3 «лампы» у верхнего края + 3 луча вниз (белый 55% прозрачности, розовый 14%, голубой 30%) + светлое пятно «сцены» внизу. Лучи мягко мерцают по очереди (CSS-анимация `opacity`, 3.4 с).
- **Кнопки**: высота 56–62 px, `border-radius: 999px`. Главная — тёмная `#1A1020` с розовым текстом или розовая `#E0167A` с белым.
- **Варианты ответа**: «таблетки» с рамкой 2 px `#1A1020`, буква A–D в кружке слева. Выбранный вариант закрашен тёмным.
- **Фото к вопросу**: белая рамка 7 px, радиус 22 px, лёгкий поворот −1.5°, розовая наклейка в правом верхнем углу (`«это база»`, `«драма»`, `«мотор!»` и т. п. — тексты есть в макетах).
- **Прогресс**: сверху «Вопрос N» и «N / 23», под ними розовая полоска.
- Все анимации отключаются при `prefers-reduced-motion: reduce`.

## 4. Поток экранов

```
Приветствие → Вопрос 1 → Реакция → Вопрос 2 → Реакция → … → Вопрос 23 → Реакция
→ Перед подарком → Самолёт (потряси телефон) → Никита с парашютом → Билет
```

### 4.1 Приветствие (`00-welcome.html`)
- Розовый шнурок сверху, на нём бейдж «Проход везде · Пропуск за кулисы · НИКИТА · главный герой дня», круглое фото Никиты на бейдже. Бейдж слегка покачивается.
- В бейдже: «Статус: иконка», «Дата: [ДАТА]», «Испытание: 23 вопроса», «Кринж: 0%».
- «С днюхой, зай!» + «23 вопроса — по одному за каждый твой год. Пропуск активируется в конце. Ошибёшься — не кринж, подарок всё равно твой».
- Кнопка «Погнали».

### 4.2 Экраны вопросов — по типу из `questions.json`

Всегда сверху: прогресс, фото/видео в рамке, вопрос. Ниже — блок ответа по типу:

- **`text`** (`q01-text.html`): метка «Твой ответ», поле ввода, под ним «Большие или маленькие буквы — неважно». Кнопка «Мой ответ финальный» неактивна, пока поле пустое.
- **`choice`** (`q02-choice.html`, `q06…`, `q17…`): 4 варианта-таблетки (для вертикального видео — сетка 2×2). Кнопка неактивна, пока ничего не выбрано.
- **`match`** (`q04-match.html`): белая карточка со списком последствий A–D, ниже имена и рядом с каждым кнопки A B C D. Каждая буква выбирается только одним человеком. Кнопка активна, когда выбраны все 4 пары.
- **`voice`** (`q03-video-voice.html`, `q05-voice.html`): плашка с пульсирующим микрофоном «Отвечай вслух» + текст `voicePrompt`. Внизу подпись «Для жюри» и две кнопки: «Мимо» и «Засчитано».
- **`hidden_photo_text`** (`q07-hidden-photo.html` → `q07-hidden-photo-revealed.html`): фото сильно размыто (`filter: blur(22px)`), поверх замок и «Фото откроется после ответа». После отправки фото плавно проявляется (blur → 0 за ~0.8 с), поле подсвечивается и появляется `revealText`.
- **Подсказка** (вопрос 14, поле `hint`): розовая пунктирная плашка с лампочкой под полем: «Подсказка: …».
- **Видео**: `<video controls playsinline preload="metadata" poster=…>`. Горизонтальное — во всю ширину, вертикальное — узкой карточкой ~180 px по центру. Автоплей не нужен, Никита запускает сам.
- **Вопрос 10**: после ответа можно показать стикер `assets/q10-sticker.png` как разгадку.

### 4.3 Реакция на ответ (`90-answer-correct.html`)
Отдельный экран после каждого вопроса. Сверху тот же прогресс.

**Верно**: круглое фото Никиты + розовый штамп-звезда «верно · допущен» (покачивается), большой заголовок, короткая реплика, плашка «Ещё на шаг ближе к подарку», кнопка «Дальше».
Заголовки чередуй случайно: «SLAY.», «Это база», «Имба», «Грин флаг засчитан», «Абсолютное кино», «Ну всё, я плак».

**Неверно** (макета нет — сделай в том же стиле, без зелёного/красного «ошибка»): заголовок из набора «Ну такое…», «Зай, это кринж», «Ред флаг… шучу, люблю», «Ору. Нет.» + показать правильный ответ + «Но ты всё равно иконка». Кнопка «Дальше».

Для `voice` реакция зависит от кнопки жюри. Подарок открывается в любом случае — счёт ни на что не влияет.

### 4.4 Перед подарком (`91-before-gift.html`)
Тёмный бейдж на шнурке «Доступ открыт» с огромным розовым «?» и «подарок внутри». Текст: «Все проверки пройдены» / «Ты прошёл. Теперь самое жёсткое» / «Внутри — подарок от [ОТ КОГО]. Сядь. Подыши. Готов?» Кнопка «Открывай, я готов», под ней «Держи телефон крепче».

⚠️ **Именно по нажатию этой кнопки запроси доступ к датчику движения** (iOS 13+ требует жест пользователя):
```js
if (typeof DeviceMotionEvent?.requestPermission === 'function') {
  await DeviceMotionEvent.requestPermission(); // 'granted' | 'denied'
}
```

### 4.5 Самолёт — «Потряси телефон!» (`92-plane-shake.html`)
- Розовое небо, облака плывут справа налево, розовый самолёт покачивается, на двери «?».
- «Подарок уже в воздухе» / «Потряси телефон!» / «Сильнее. Ещё сильнее. Кажется, сейчас что-то выпадет…»
- Иконка трясущегося телефона и полоска «Тряска N%».
- Логика: слушать `devicemotion`, считать силу тряски (например, модуль `accelerationIncludingGravity` минус ~9.8, сглаженный). Каждое сильное встряхивание добавляет к полоске; на 100% — короткая вибрация (`navigator.vibrate?.(200)`, если есть), вспышка и переход на следующий экран.
- Запасной вариант всегда виден: ссылка «Не трясётся? Нажми сюда». Её же показывать, если доступ к датчику не дали или датчика нет.

### 4.6 Никита с парашютом (`93-parachute-drop.html`)
- Никита (фото лица в круге) висит под розово-бело-голубым куполом и медленно покачивается, облака проносятся вверх, падает конфетти, вдали улетает самолёт.
- Хорошо бы, чтобы он «выпадал» сверху: старт за верхним краем → плавное падение на место (~1.5 с) → покачивание.
- «Ты прыгаешь с парашютом!!!» / «Это не шутка. Это твой подарок от [ОТ КОГО]». Кнопка «Посмотреть билет».

### 4.7 Билет (`94-ticket.html`)
Бейдж-«посадочный пропуск» на шнурке: «Проход в небо», «НИКИТА», «вайб: свободное падение», поля: Формат [ТАНДЕМ], Высота [ВЫСОТА] м, Дата [ДАТА], Статус: иконка, Аэродром [НАЗВАНИЕ АЭРОДРОМА], № [НОМЕР СЕРТИФИКАТА]. Падает конфетти.
«Вот твой билет в небо» / «Энергия главного героя — на высоте [ВЫСОТА] м».
Кнопки: **«Сохранить билет»** (сохранить картинку билета: html-to-image или canvas → PNG) и **«Похвастаться»** (Web Share API, иначе тоже скачать картинку).

## 5. Проверка текстовых ответов

```
normalize(s) = s.toLowerCase()
                .replace(/ё/g, 'е')
                .normalize('NFD').replace(/[̀-ͯ]/g, '')   // š → s
                .replace(/[«»"'.,!?()-]/g, ' ')
                .replace(/\s+/g, ' ').trim()
```
Засчитывать, если `normalize(ввод)` равно `normalize(answer)` или любому из `aliases`, **или** содержит его как целое слово/фразу. Допускай 1 опечатку для слов длиннее 5 букв (расстояние Левенштейна ≤ 1). Лучше засчитать лишнее, чем обидеть именинника.

## 7. Проверка перед отправкой Никите

1. Пройти весь квиз на настоящем iPhone и Android по HTTPS-ссылке.
2. Проверить, что все видео играют на iPhone (`playsinline`), а фото не обрезают лица.
3. Проверить тряску и запасную ссылку «Нажми сюда».
4. Закрыть вкладку посреди квиза и открыть снова: должен продолжиться с того же места.
5. Включить «Уменьшить движение» в настройках телефона: анимации должны пропасть, всё остальное работать.
